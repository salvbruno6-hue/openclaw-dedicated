# Lobster

Workflow shell nativo para OpenClaw

## Características
- CLI nativa para workflows
- Suporte a scripts automatizados
- Integração com o ecossistema OpenClaw
- Ambiente de desenvolvimento

## Estrutura
```
lobster/
├── src/
│   ├── cli/
│   ├── shell/
│   └── commands/
├── examples/
└── docs/
```
