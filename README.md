## 🚀 Começando

### Clone do OpenClaw Official
```bash
git clone https://github.com/openclaw/openclaw.git
cd openclaw
```

### Instalação
```bash
npm install
# ou
yarn install
```

### Inicializar com Governança
```bash
# Configurar token de autenticação
export OPENCLAW_TOKEN="seu_token_aqui"

# Conectar ao Elo Cognitivo IA
openclaw init --governance=true
```
