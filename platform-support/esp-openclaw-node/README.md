# ESP OpenClaw Node

Supporte para Sistemas Embarcados (ESP32, Arduino)

## Funcionalidades
- Suporte a ESP32
- Suporte a Arduino
- Compilação otimizada
- Gerenciamento de recursos limitados

## Estrutura
```
esp-openclaw-node/
├── src/
│   ├── esp/
│   ├── arduino/
│   └── firmware/
├── build/
└── examples/
```
